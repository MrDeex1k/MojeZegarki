# Zgłoszenia i dyskusje

Moje Zegarki jest projektem source available rozwijanym wyłącznie przez właściciela. Repozytorium nie przyjmuje zewnętrznych wkładów kodowych.

## Co można zgłaszać

- błędy i problemy z działaniem przez GitHub Issues;
- propozycje zachowania lub funkcji przez GitHub Issues;
- pytania i rozmowy przez GitHub Discussions;
- podatności bezpieczeństwa wyłącznie przez prywatny formularz opisany w [SECURITY.md](SECURITY.md).

## Czego nie należy przesyłać

Nie należy otwierać Pull Requestów ani publikować patchy, gotowych implementacji lub fragmentów kodu w Issues i Discussions. Opis problemu powinien zawierać obserwowane zachowanie, oczekiwany rezultat, kroki odtworzenia oraz informacje o urządzeniu i wersji systemu, jeśli są istotne.

Właściciel samodzielnie decyduje o zakresie i sposobie implementacji zgłoszonych pomysłów. Przesłanie zgłoszenia lub udział w dyskusji nie oznacza dołączenia do projektu ani uzyskania praw do jego kodu, nazwy lub materiałów.
